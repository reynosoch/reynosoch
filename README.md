## Current Work

Some of my current work lives in private repositories, so the descriptions here stay focused on engineering scope and public-safe details.

### Industrial Data & Reconciliation Systems

Internal applications that ingest spreadsheet-based datasets, normalize records, apply domain logic and turn differences into traceable, reviewable information.

`React` · `Vite` · `TypeScript` · `Supabase` · `PostgreSQL` · `Dexie / IndexedDB` · `TanStack Virtual` · `PGlite` · `XLSX` · `PapaParse`

### Asset Audit & Tracking

Responsive web tooling for structured asset management, auditing, real-time updates, mobile workflows, imports/exports and traceability.

`React` · `Vite` · `Tailwind CSS` · `Supabase Realtime` · `PostgreSQL` · `Motion` · `XLSX`

### Spreadsheet Delta Monitoring

A lightweight browser tool for comparing changing spreadsheet datasets and surfacing reviewable differences without turning the workflow into another giant spreadsheet.

`React` · `Vite` · `Vitest` · `ESLint` · `read-excel-file`

### Viral Studio

Creative and product-oriented frontend work focused on branding, storytelling, motion and modern web experiences.

`React` · `TypeScript` · `GSAP` · `Lenis` · `Motion`

## Build Approach

```text
real problem
    ↓
raw data / workflow
    ↓
parsing + normalization
    ↓
domain logic
    ↓
validation
    ↓
ui + evidence + exports
    ↓
automation + iteration
```

```text
Useful > flashy
Simple > clever
Systems > chaos
Automation > repetitive work
Shipping > waiting for perfect
```
